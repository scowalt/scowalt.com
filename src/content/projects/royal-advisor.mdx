## Why I Built This

The Royal Advisor from [Majesty Gold HD](https://en.wikipedia.org/wiki/Majesty:_The_Fantasy_Kingdom_Sim) is one of my favorite video game characters. I wanted to bring his voice back to life as something you could type any text into and hear him say.

## How I Built It

The voice model is trained using [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS), an open-source voice cloning system. I used Claude to extract and clean audio samples from the original game files, then trained the model on my home GPU.

The inference backend is a Python API wrapping GPT-SoVITS, running on my home GPU.

## What I'm Most Proud Of

How scrappy the whole thing is. Voice cloning felt like something that required a massive dataset and expensive cloud GPUs, but I got a convincing result running on consumer hardware with a handful of game audio clips. The AI models, both the ones helping me code it and the actual voice model itself, have come astonishingly far. The gap between "this seems impossible" and "this works on my desktop" keeps shrinking.
